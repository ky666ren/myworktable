# 🚀 支线工作台 SideQuest

一个为 ADHD 大脑设计的个人支线工作台：**今日概览 + 番茄钟 + 无限画布 + 沉浸模式 + 反向 OKR**。纯原生 HTML/CSS/JS，零依赖、数据存本机，**支持安装成手机/电脑应用（PWA）+ WebDAV 多端同步**。

## 快速开始

- **电脑**：直接双击 `index.html`（Chrome/Edge），或 `node server.js` 后访问 http://localhost:8123
- **手机（同一局域网）**：电脑运行 `node server.js`，手机浏览器访问 `http://电脑局域网IP:8123`（Windows 查 IP：`ipconfig` 里的 IPv4 地址）
- **像 App 一样安装（推荐）**：把整个文件夹部署到免费 HTTPS 托管（见下文「安装为 App」），手机/电脑浏览器打开后「添加到主屏幕 / 安装应用」，即得全屏独立窗口 + 离线可用

## 安装为 App（PWA）

1. 注册任意免费静态托管（Vercel / Cloudflare Pages / GitHub Pages），把本文件夹整个上传/拖拽部署
2. 用手机浏览器打开分配的 `https://xxx` 地址
3. 安卓 Chrome：菜单 →「安装应用」；iOS Safari：分享 →「添加到主屏幕」
4. 装好后是独立全屏窗口、有桌面图标、断网也能用（Service Worker 离线缓存）

> 说明：Service Worker 只在 https / localhost 下生效，属浏览器安全规则。局域网 IP 访问时没有安装提示，功能不受影响。

## 手机电脑数据同步（WebDAV）

数据默认存各自设备的浏览器里，开启云同步后多端保持一致：

1. 注册[坚果云](https://www.jianguoyun.com)（免费），进入「账户信息 → 安全选项 → 添加应用密码」，生成一个应用密码
2. 应用「设置 → ☁️ 云同步」：地址保持默认 `https://dav.jianguoyun.com/dav/`，账号填注册邮箱，密码填**应用密码**（不是登录密码）
3. 点「🔄 智能同步」：
   - 云端没有数据 → 上传本机
   - 云端较新 → 下载覆盖本机（会确认，页面刷新一次）
   - 本地较新 → 上传覆盖云端（会确认）
   - 两边一样 → 提示已是最新
4. 打开「自动同步」后每 30 分钟自动比对一次；也可随时手动「⬆️ 上传覆盖云端」/「⬇️ 从云端恢复」

策略是**最后写入胜出**（按全局 updatedAt），冲突时永远先弹确认框，不会静默覆盖。同步走浏览器直连；若坚果云跨域拦截，用 `node server.js` 打开时会自动走本地代理（`/dav-proxy`）。应用密码只存本机浏览器。

## 每日复盘（马伯庸日记模板）

每天一页，只记客观事实、拒绝情绪内耗：

- 📍 **今日要事 Action** —— 时间/地点/人物/事件（**每行会进入反向 OKR 的行为发现引擎**）
- 🍱 **生活记录 Life** —— 衣食住行、外卖测评、影音娱乐
- 📚 **今日书账 Input** —— 阅读页码、金句、购书清单
- ⚡ **今日灵感 Spark** —— 一键「扔到画布」变成便签
- 🧠 **今日新知 Knowledge** —— 冷知识、避坑、新技能
- 💤 **睡眠评分 Sleep** —— 入睡/起床时间 + 1-5 星打分

## 反向 OKR：让目标从行为里「长出来」

传统 OKR 要先定目标再拆解，对 ADHD 大脑很难起步。这里反过来：

1. **只管记录**——打番茄、完成任务、在复盘里写今日要事，都是行为足迹
2. **自动发现**——引擎用中文 bigram 相似度聚类，重复 **≥3 次且跨越 ≥2 天**的行为自动浮出，附证据（哪几天、几次、多少分钟）
3. **一键生长**——点「🌱 生长成 OKR」，自动生成 O（如「把『背个单词』养成稳定节奏」）+ 三条数值 KR（30 天频次 / 每周覆盖天数 / 累计分钟），目标值按当前量上浮约 50%
4. **进度自动更新**——之后的行为自动匹配计入进度条，三条全满自动达成 🏆
5. **可选 AI 润色**——设置页填 API Key（默认智谱，兼容 OpenAI 格式）后，目标卡出现「✨ AI 润色」按钮优化措辞；不填完全不影响
6. 也支持手动建目标、放下（💤）、重新生长、删除

## 沉浸模式 🚀

给任务填好链接材料，点任务旁的 🚀：所有链接一键铺开（B站/YouTube 内嵌播放，抖音/小红书/飞书等禁止内嵌的网站自动变卡片+新标签打开）、画布沉入背景、番茄钟自动开始、左侧任务简报可勾微步骤，`Esc` 退出。

## 画布操作

- **手机**：单指空白拖=平移、单指拖节点=移动、**双指捏合=缩放**、双击=建便签/编辑；视频节点顶部有拖动条
- **电脑**：双击空白=便签、滚轮=缩放、拖空白=平移、`Ctrl+V` 粘贴图片/文字上画布、拖图片文件进画布
- **箭头工具**：点起点节点 → 再点终点节点，箭头随节点移动
- **多画布**：左上角 🗂 切换 / 重命名 / 删除 / 新建，每张画布独立记住视角
- 快捷键：`V` 选择 `N` 便签 `T` 文字 `A` 箭头 `S` 符号，`Del` 删除，`Ctrl+Z` 撤销

## 调研依据

- **NeuroHacks Lab FocusLab**：棕噪音 + 番茄钟 + 免费即用 → 本项目的声音掩蔽与零门槛策略
- **Super Productivity**（13k+ ★，活跃）：任务绑定计时记录
- **Flowtime/Flowmodor**：正计时模式，不粗暴打断心流
- **tldraw / Excalidraw / AFFiNE**（合计 180k+ ★）：无限画布交互范式
- **Logseq daily journal / KPT 复盘法**：每日一页 + 结构化复盘 → 马伯庸日记模板的实现参考
- **OKR 方法论的反向应用**：行为先行、目标后置，适配「定不出目标」的真实状态

## 技术要点

- 零依赖单页应用，`file://` 直接可用；localStorage 持久化，计时器刷新不丢
- 移动端 ≤900px 自动切换为底部图标栏布局，专注运行时导航图标闪小圆点
- 视频嵌入策略：B站官方播放器 / YouTube embed / 直链 mp4；禁止内嵌站点自动降级卡片
- 行为聚类：中文 bigram + union-find，全部本地计算，数据不出本机（AI 润色仅在配置 Key 后按需调用）

## 已知限制

- 抖音、小红书、飞书等网站禁止被内嵌，只能以卡片 + 新标签打开（B站、YouTube 不受影响）
- 行为发现基于文本相似度，措辞差异太大的同一行为可能聚不在一起；多写几条相近的记录即可
- PWA 离线缓存与「安装应用」只在 https / localhost 生效；file:// 与局域网 IP 访问时功能完整但无安装能力
- WebDAV 同步为最后写入胜出策略，适合单人多设备；两端同时改动时后保存的一方会覆盖，重要节点请用「导出 JSON」留底
